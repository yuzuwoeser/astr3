# ASTR3 distributions

Choose the npm tarball for a bundled application, the browser ZIP for a plain
website, or the WordPress ZIP for an installable chart block. Stack-specific
starter ZIPs include the ASTR3 tarball and standalone application files.

Browser bundles include optional local calculations, SVG/PNG export modules,
appearance presets, and license notices. Serve them over HTTP/HTTPS.

WordPress requires 6.5+ and PHP 8+. Upload the plugin ZIP, activate ASTR3, and add
an ASTR3 Chart block using supplied JSON. No theme edits or npm install needed.

Verify assets against SHA256SUMS. manifest.json records the version, source
commit and artifact hashes. See CHANGELOG.md at the tagged commit for changes,
and docs/installation.md for integration instructions.
