ASTR3 / Righteous five-color wordmark

Use ASTR3 in display names and prose; package imports, URLs, CSS classes, and
JavaScript identifiers use astr3. Branding does not change the library API.

astr3-logo.svg: transparent, portable outlines of the original font glyphs.
astr3-logo-preview.svg: the same artwork on the dark presentation background.
palette.json: exact character colors and background from the logo bundle.

A: Mint #76C7B2
S: Sky blue #80B9EE
T: Lavender #B5A0E8
R: Coral #EF9399
3: Gold #EACB92
Background: #111C20

Keep the light character colors on the dark background for contrast. The demo
uses live text in the original, unmodified Righteous Regular (400), with native
spacing, rather than loading an image.

The live text keeps the font's native spacing and remains readable if the font
cannot load. The SVGs contain the original glyph outlines and require no
installed font. ASTR3 source is MIT licensed; the font and its glyph artwork
retain their SIL OFL license and notices.
